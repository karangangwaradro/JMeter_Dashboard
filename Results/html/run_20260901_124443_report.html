📐 Calculation Methodology & Reliability Framework

SLA Deviation %

Calculates how far actual P90 exceeds target P90.
Deviation = ((Actual P90 - Target P90) / Target P90) * 100

Apdex (Application Performance Index)

Measures user satisfaction. Evaluates response times against target T and 4T boundaries, deducting for errors.
Score = (Satisfied + (Tolerating / 2)) / Total

Response Time Percentiles (P90/P95/P99)

The time within which N% of requests were completed. Used instead of averages to highlight tail latency and true user experience.

Error Rate

Percentage of total transactions that failed application or HTTP validation assertions.
